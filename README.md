# navplace

NavPlace is a tool for organizing, navigating, and presenting your links from a single text-based source.

**[Website](https://navplace.com/)**

## Quick start

Download the AppImage from [releases/latest](https://github.com/vbarbarosh/navplace/releases/latest), then:

```bash
chmod +x NavPlace-*.AppImage
./NavPlace-*.AppImage
```
