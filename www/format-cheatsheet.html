NavPlace

Format cheatsheet

A NavPlace document is plain text. One line is one thing, and the first character of the line decides what that thing is. The same document feeds the desktop app, a hosted page, and an embedded widget.

Legend

Symbol Where Means
% key: value own line A directive for the whole document.
# Section own line A section for every link line below it.
| in # Section, % ns: Separates names.
label  url own line One link. The url ends the line.
#tag in a link line A tag. Searchable.
#key=value in a link line A value for the design. Not searchable.
@name after a label, before the url An image at ~/.navplace/name.

Any other line is skipped without a message.

Example

% design: showcase
% title: Vladimir Barbarosh

# GitHub | Work
node-helpers                                     https://vbarbarosh.github.io/node-helpers
vue-modal          #frontend                     https://vbarbarosh.github.io/vue-modal
Gmail              #mail #padding=1 @img/gm.png  https://mail.google.com/
                                                 https://www.linkedin.com/in/vbarbarosh/
  • % design: picks the design. % title: hands it free text.
  • # GitHub | Work puts the four links below it in two sections.
  • #frontend and #mail are tags. #padding=1 reaches the design as meta.padding.
  • @img/gm.png shows ~/.navplace/img/gm.png next to Gmail.
  • The last link has no label. It becomes www.linkedin.com/in/vbarbarosh/.

Directives

Directive Effect
% design: x A folder name under designs/. The embed widget uses basic when absent.
% title: x Text for the design's title element.
% email: x Text for the design's email element. showcase also copies it into href.
% ns: a | b Keeps only the links that sit under a section named a or b.
% include: u Desktop app only. Pulls the document at url u and appends its links.
% other: x Free. The design reads it as meta.other.
  • A directive is valid anywhere in the file, not only at the top.
  • The value is required. % oops stops the parse with an error.
  • The same key twice: the last one wins.
  • Keys keep their case. % Design: and % design: are two keys.

Include — desktop app only

% include: https://example.com/links.md #work #prefix=ACME

The desktop app pulls the document and appends its links. The web app and the embed widget read the directive and do nothing with it.

Option Effect
#tag Adds a tag to every pulled link. Repeatable.
#prefix=x Puts x and a space in front of every pulled label.
#suffix=x Puts a space and x after every pulled label.
  • Repeatable. Every line adds one source, in file order, and pulled links land after the local ones.
  • The url must return the document as plain text over http:// or https://.
  • A pulled document contributes links and sections only. Its directives are dropped: no design change, no % ns:, no third document.
  • The pull runs first and % ns: after it: your filter gates pulled links too.
  • The prefix and the suffix reach the search text: typing the prefix finds the pulled links.
  • The request carries no access token. An include url is a stranger.
  • A url that fails is logged and skipped. Each url gets 5 seconds before it is abandoned.
  • No pull runs in front of the window: it opens on the local links and redraws when the pulled ones arrive.

Sections, links, tags, images

  • A section applies to every link line below it, until the next section. A blank line does not end it.
  • Sections are metadata. No design in this repo draws them: % ns: filters on them, and a design can read item.namespaces.
  • Two heading lines in a row join into one block: # Work then # Fun gives one section named Work Fun.
  • The url ends the line. http://, https:// and file:// are recognized.
  • The label is optional. Without one, NavPlace builds it from the url: the host, plus the path when the path is not /.
  • Tags and #key=value pairs may sit before or after the label. Both drop out of it.
  • Tag names accept a..z, A..Z, 0..9, _ and -. A value runs to the next space or #.
  • @name becomes private://name, which the Electron app serves from ~/.navplace/.

What a link becomes

Field From
label What is left of the line after the url, tags and image are removed.
href The url.
icon_url app://favicon/<host> in Electron, /icon/<host> on navplace.com, icon.horse elsewhere.
image_url private://<name> from @name, else null.
tags Every #tag on the line.
meta Every #key=value on the line.
search1 Label and tags, lower case, Cyrillic transliterated to Latin.
search2 The url, same treatment.
namespaces The names of the section above the line.

Search expressions

Input Matches
git Contains git.
^git Starts with git.
git$ Ends with git.
!git Does not contain git.
git/api Contains both git and api.
gh mail Two expressions. Enter opens the top match for each.

The filter runs against search1 first, then search2. Transliteration works one way: git finds an item labeled Гитхаб.

Gotchas

  • The url must end the line. Text after it drops the whole line.
  • A line that starts with # is a section, never a link. Put tags after the label.
  • @name needs a space in front of it. @img.png https://… becomes the label.
  • Tag names are ASCII. #дев stays in the label as plain text.
  • A line with no url is skipped in silence. A broken % line throws.
  • % include: is inert outside the desktop app.

The parser is the source of truth: lib/parse.js. Longer notes live in docs/format.md.
