Three moves, and you are there

No tabs to hunt for, no bookmarks bar to dig through. The same few moves, dozens of times a day.

  1. CtrlShiftAltN

    Open

    The window shows at once. NavPlace stays running in the background, so there is nothing to start.

  2. mail

    Type a few letters

    Links narrow down by name, tag and address as you type; the top match is ready to go.

  3. Enter

    Go

    The link opens in your browser and the window hides, ready for the next time.

Several at once: git mail cal opens the top match for each word, your whole morning in one line.

Your links are one text file

No account and no database. A name and an address on each line; edit it in any editor.

  • It lives at ~/.navplace/README.md; the app reads it again every time you press the hotkey.
  • # A heading groups links.
  • % design: picks the look; any NavPlace design runs full-window.
~/.navplace/README.md
% design: github

ChatGPT          https://chatgpt.com/
GitHub           https://github.com/
Gmail            https://mail.google.com/
Google Calendar  https://calendar.google.com/
Google Drive     https://drive.google.com/
MDN Web Docs     https://developer.mozilla.org/
Node.js          https://nodejs.org/en/docs
Electron         https://www.electronjs.org/docs/latest/

Set up in a minute

One AppImage, nothing to install system-wide.

  1. 1. Download

    The latest release, a single AppImage file.

    Download for Linux

  2. 2. Run

    Make it executable and start it.

    chmod +x NavPlace-*.AppImage
./NavPlace-*.AppImage

  3. 3. Add the hotkey

    Once, on GNOME, in the app: the gear , then GNOME setup, Set up. It registers CtrlShiftAltN. Needs node on your PATH.

    Or from a terminal:

    ./NavPlace-*.AppImage --configure-gnome
